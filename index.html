YouTube Factory

A private publishing tool for the science-facts channel @ablaihangalimov5131.

YouTube Factory is an internal tool used only by the owner of the channel above. It prepares short educational science videos in Russian, Kazakh and English (script, narration, captions, licensed stock footage from Pixabay) and uploads them to the owner's own YouTube channel through the YouTube Data API v3.

What it does with the YouTube API

  • Uploads videos created by the channel owner to the owner's own channel (videos.insert).
  • Sets the video thumbnail (thumbnails.set).
  • Reads the owner's own channel ID to make sure uploads go to the correct channel (channels.list with mine=true).

The tool is not offered to other users, does not access other people's channels and does not collect data about viewers. Every video is labeled as containing synthetic (AI-generated) media.
